# Retro Arcade Dual-Pack

A small browser arcade with two games, built with plain HTML, CSS and vanilla JavaScript. No frameworks or libraries.

## Games
- **Memory Matrix**: watch a growing sequence of lit tiles and repeat it. Score is the number of rounds completed.
- **Speed Reflex**: click the moving target as many times as you can in 30 seconds. Shows reaction time in milliseconds.

Both games have instructions, live results, a score counter, a best score (saved in the browser) and a restart button.

## Run locally
1. Download or clone this folder.
2. Double-click `index.html` to open it in your browser.

## Background music
Put your own audio file at `assets/background.mp3` and press the **Music** button in the top bar.

## Files
| File | Purpose |
|------|---------|
| `index.html` | Page structure and both games' markup |
| `style.css` | All styling, colours and page switching |
| `script.js` | Game logic, sound and music |

## Tech
HTML5, CSS3, vanilla JavaScript.
